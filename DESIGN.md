## 2. View Hierarchy

Six views, each with defined primary/secondary/tertiary content priority.

### Overview (price summary + market context)

```
1° Summary Pills      — median, mean, fair range (glanceable)
2° Market Signal      — anomaly/heat indicator (if present)
3° Listing Cards      — scrollable, secondary to stats
4° Price Chart        — expandable, lowest priority
```

### Ads (search + browse listings)

```
1° Search Bar         — primary action, always visible
2° Filter Pills       — refine results, secondary
3° Listing Cards      — results, the main content
```

### Tracking (saved queries + alerts)

```
1° Active Trackers    — what's being monitored (primary)
2° New Events Badge   — unread alerts (attention signal)
3° Event Details      — per-tracker, expandable
   • NEW LISTING → green dot (visual distinction)
   • PRICE DROP → red dot (visual distinction)
4° Add Tracker CTA    — always accessible
```

### Cheap (discounted deals)

```
1° Discount Badges    — biggest savings first
2° Deal Cards         — sorted by discount %
```

### Monitoring (watchlist)

```
1° Watchlist Cards    — monitored items (primary)
2° Price Change       — ↑↓ arrows with delta (attention)
3° Add to Watchlist   — always accessible
```

### Deals (pipeline + profit)

```
1° Pipeline Tabs      — new/researching/bought/sold
2° Lead Cards         — items in current status
3° Profit Dashboard   — total profit, ROI (secondary)
4° Expense Breakdown  — expandable per lead
```

## 3. Interaction States

### Current Coverage

| Feature | Loading | Empty | Error | Success |
|---------|---------|-------|-------|---------|
| Search/Listings | Skeleton | buildEmptyState | Error bar | Cards |
| Trackers | **missing** | buildEmptyState | Toast | Cards |
| Tracker Events | **missing** | buildEmptyState | Toast | Events |
| Watchlist | **missing** | buildEmptyState | Toast | Cards |
| Deals | Skeleton | buildEmptyState | Toast | Cards |
| AI Analysis | Spinner | N/A | Toast | Result |
| Expenses | Skeleton rows | "Нет расходов" | Toast | Rows |

### Required Additions

1. **Skeleton trackers** — 2-3 placeholder tracker cards while loading
2. **Skeleton watchlist** — 2-3 placeholder watchlist cards while loading
3. **First-time empty states:**
   - Overview: "Найдите выгодную сделку на Kufar" + search CTA + illustration
   - Tracking: "Создайте первый трекер" + CTA with icon
   - Deals: "Добавьте первую сделку" + CTA with icon
4. **Retry on error** — Error bar should include "Повторить" button

### Empty State System

Reusable `buildEmptyState()` in `render_core.js:273-306`:
- Parameters: icon, title, hint, optional CTA button
- Icons defined in `_EMPTY_STATE_ICONS` map
- Pattern: check `typeof buildEmptyState === "function"`, fallback to plain text

## 4. User Journey

### First-time User Flow (to implement)

```
1. Opens app from Telegram → sees guided empty state
2. "Найдите выгодную сделку на Kufar" CTA → focuses search bar
3. Types query, searches → sees results
4. Wants to track → "Создайте трекер" CTA on tracking tab
```

### Notification Deep Links (to implement)

```
1. Gets Telegram notification → taps inline button
2. Opens mini app with start_param → auto-switches to Tracking tab
3. Expands relevant tracker → shows new events
```

### Deal Pipeline Narrative

```
Найдено → Отслеживается → В работе → Продано
   (green)    (blue)       (amber)    (success)
```

Progress indicator connecting the steps visually.

## 5. Accessibility

### Current Strengths

- Skip link: `<a href="#main-content" class="skip-link">`
- Tab navigation: `role="tablist"`, `aria-selected`, `aria-controls`
- Modals: `role="dialog"`, `aria-modal="true"`, focus trap
- Focus visible: `2px solid var(--accent)` + `4px accent-soft` shadow
- Touch targets: 44px minimum on all interactive elements
- Reduced motion: 14+ media queries + JS check
- `sr-only` class, `aria-hidden` on decorative SVGs/canvases
- `aria-live="polite"` on listing containers
- `role="alert"` on error bar

### Required Fixes (WCAG AA)

1. **Color contrast:**
   - Dark theme: `--text-muted` `#858585` → `#a0a0a0` (5.5:1 on `#0a0a0b`)
   - Light theme: `--text-muted` `#6b6b6b` → `#5a5a5a` (7:1 on `#f7f7f8`)
   - Same for `--text-secondary`
2. **Image alt text:**
   - Listing thumbnails: `alt=""` → `alt="${item.title || 'Товар без названия'}"`
   - AI analysis: `alt=""` → `alt="Лучшая альтернатива: ${title}"`
   - Tracker events: `alt=""` → `alt="Фото: ${listingTitle}"`

### Deferred (Medium)

- Focus restoration after modal close
- `aria-label` on dynamically created buttons (lead/watch)
- Tooltips visible on keyboard focus
- `<fieldset>` + `<legend>` for filter groups
- Smooth scroll respects `prefers-reduced-motion`

## 6. Visual Coherence

### Token Adoption Rates

| Property | Token-based | Hardcoded | Adoption |
|----------|-------------|-----------|----------|
| border-radius | 281 | 37 | 88% |
| color (text) | ~200+ | 1 | 99% |
| background | ~200+ | 2 | 99% |
| box-shadow | 77 | 59 | 57% |
| font-size | 82 | 504 | **14%** |
| padding | 40 | 326 | **11%** |
| transition duration | 0 | 20 | **0%** |

### Required Migration

1. **Font-size** — Migrate 504 hardcoded `font-size: Npx` to `var(--text-*)` tokens
2. **Padding** — Migrate 326 hardcoded `padding: Npx` to `var(--space-*)` tokens

### Migration Rules

| Hardcoded value | Nearest token |
|-----------------|---------------|
| 10px | `var(--text-xs)` |
| 11px | `var(--text-s)` |
| 12px | `var(--text-sm)` |
| 13px | `var(--text-base)` |
| 14px | `var(--text-md)` |
| 16px | `var(--text-lg)` or `var(--space-2xl)` |
| 18px | `var(--text-xl)` |
| 20px | `var(--text-2xl)` or `var(--space-xl)` |
| 24px | `var(--text-3xl)` or `var(--space-2xl)` |
| 32px | `var(--text-4xl)` or `var(--space-3xl)` |

Context determines whether a value is typography (text-*) or spacing (space-*).

## 7. AI Slop Assessment

**Result: PASS** — No hard rejection criteria triggered.

- No generic SaaS card grid as first impression
- No hero image with weak brand
- No carousel without narrative purpose
- No purple/violet gradient backgrounds
- No 3-column feature grid with icons-in-circles
- No emoji as design elements
- No decorative blobs/wavy dividers
- No cookie-cutter section rhythm
- Primary font is Geist (not system-ui)
- Brand unmistakable in first screen ("Rafuk" logo)

**Note:** Accent colors `#3b82f6` (blue-500) + `#a78bfa` (violet-400) are the most common AI-generated UI palette. Accepted because the dark theme, Geist font, and utility-first layout override the default-blue concern.
