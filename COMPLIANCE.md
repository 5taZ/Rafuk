# Rafuks — Требования законодательства Республики Беларусь

> Дата: 2026-04-27
> Контекст: Telegram Mini App для аналитики kufar.by с AI-помощниками (Google Gemini, США)

---

## 1. Персональные данные (Закон РБ №91-З от 07.05.2021)

### 1.1. Какие ПД обрабатываются сейчас

| Категория | Данные | Источник | Хранение |
|-----------|--------|----------|----------|
| Идентификация | `telegram_user_id`, `first_name`, `username` | Telegram initData | `users` таблица |
| Поисковая активность | поисковые запросы, фильтры (категория, регион, состояние) | Пользователь | `trackers` |
| Финансовые | `buy_price_byn`, `sold_price_byn`, `target_resale_byn`, `amount_byn` (расходы) | Пользователь | `lead_items`, `deal_expenses` |
| Поведенческие | `notes` (заметки к лидам), `query` (запросы трекеров) | Пользователь | `lead_items`, `trackers` |

### 1.2. Трансграничная передача данных

**Критическая проблема.** Данные передаются в Google Gemini (США):

| Что уходит | В каком виде | Юрисдикция |
|------------|-------------|-------------|
| Описание объявлений | Текст продавца (санитизированный, до 700 символов) | США |
| Фотографии объявлений | URL с rms.kufar.by (до 3 шт.) | США |
| Параметры товаров | Название, состояние, характеристики | США |
| Рыночная статистика | Медиана, Q1/Q3, количество объявлений | США |
| Контекст риска | Флаги аномалий, оценка сделки | США |
| Фото пользователя (listing assistant) | Загруженные фото товара (до 4 шт.) | США |

Закон №91-З ст.10: трансграничная передача ПД требует:
1. Уведомления субъекта ПД о стране назначения
2. Согласия субъекта ПД
3. Регистрации в уполномоченном органе (при Наццентре информатизации РБ)

### 1.3. Обязательные требования (P0)

- [ ] **Политика конфиденциальности** — модал при первом входе + ссылка в хедере приложения
- [ ] **Согласие на обработку ПД** — чекбокс или кнопка «Принять» при первом запуске
- [ ] **Уведомление о трансграничной передаче** — явное указание: «Данные обрабатываются AI-сервисом в США»
- [ ] **Эндпоинт «Удалить аккаунт»** — каскадное удаление всех ПД пользователя из всех таблиц
- [ ] **Усиленный AI-дисклеймер** — заменить текущий на расширенный (см. раздел 3)

### 1.4. Рекомендуемые требования (P1)

- [ ] **Право на экспорт данных** — эндпоинт, возвращающий все данные пользователя в JSON/ZIP
- [ ] **Логирование AI-решений** — аудит-трейл: какой запрос → какой ответ → когда
- [ ] **Хранение согласия** — таблица `user_consents` с типом согласия, датой, версией политики

### 1.5. Стратегические требования (P2)

- [ ] **Регистрация в реестре операторов ПД** — при Наццентре информатизации РБ
- [ ] **DPA с Together AI** — Data Processing Agreement, определяющий обязанности процессора
- [ ] **Исследование локального/ЕС AI-провайдера** — для устранения трансграничной передачи

## 2. AI-дисклеймеры

### 2.1. Текущий дисклеймер

```
Анализ носит информационный характер. Результаты не являются гарантией.
```

**Проблема:** Слишком общий. Приложение считает ROI, даёт советы по торгу, оценивает риски перепродажи — это может трактоваться как финансовая/инвестиционная консультация.

### 2.2. Требуемый дисклеймер

```
AI-анализ носит исключительно информационно-справочный характер и не является:
• финансовой, инвестиционной или юридической консультацией;
• гарантией прибыли, рыночной стоимости или ликвидности товара;
• рекомендацией к совершению или отказу от сделки;
• профессиональной оценкой товара (для оценки обратитесь к сертифицированному оценщику).

Все решения о покупке, продаже, цене и условиях сделки пользователь принимает
самостоятельно на свой страх и риск. Rafuk не несёт ответственности за любые
убытки, упущенную выгоду или иной ущерб, связанный с использованием
AI-рекомендаций и аналитических данных.

Рыночные данные основаны на открытых объявлениях kufar.by и могут не отражать
реальные цены сделок.
```

### 2.3. Где должен отображаться

| Место | Когда | Формат |
|-------|-------|--------|
| AI-анализ модал | При получении результата | Текст внизу результата |
| AI-помощник продавцу | При получении результата | Текст внизу результата |
| Быстрая оценка состояния | При получении результата | Текст внизу |
| Первый запуск AI | Перед первым вызовом | Полный модал с подтверждением |
| Настройки/О приложении | Всегда доступен | Ссылка «Условия использования AI» |

## 3. Согласие на AI-обработку

### 3.1. Требуемый флоу

```
Пользователь нажимает «AI анализ» впервые
  → Модал согласия:
     «AI-анализ выполняется облачным сервисом (Google Gemini, США).
      Для анализа отправляются: текст объявления, фотографии,
      параметры товара и рыночная статистика.
      
      Ваши персональные данные (имя, контакты, финансовые записи)
      НЕ отправляются в AI-сервис.
      
      [ ] Я понимаю и согласен на обработку данных AI-сервисом
      [ ] Я ознакомился с политикой конфиденциальности
      
      [Продолжить]  [Отмена]»
  → Если согласен → сохранить в БД, показать анализ
  → Если отказался → показать только не-AI данные (статистика, сегменты)
```

### 3.2. Модель данных для согласия

```python
class UserConsent(Base):
    __tablename__ = "user_consents"
    
    id: Mapped[int]          # PK
    user_id: Mapped[int]     # FK → users.id
    consent_type: Mapped[str]  # "ai_analysis" | "pd_processing" | "cross_border"
    version: Mapped[str]     # Версия политики ("2026.1")
    granted_at: Mapped[datetime]
    revoked_at: Mapped[datetime | None]  # NULL = активно
    ip_address: Mapped[str | None]  # Для аудита
```

### 3.3. Важное уточнение

Персональные данные пользователя (имя, контакты, финансовые записи) **НЕ** должны отправляться в AI-сервис. Сейчас это уже так — в AI-промпты идут только данные объявления и рыночная статистика. Но это нужно **явно указать** в согласии.

## 4. Право на удаление данных

### 4.1. Требуемый эндпоинт

```
DELETE /api/account
  → Каскадное удаление:
     - deal_expenses (WHERE user_id = ?)
     - lead_item_price_snapshots (через lead_items)
     - lead_items (WHERE user_id = ?)
     - tracker_events (WHERE user_id = ?)
     - trackers (WHERE user_id = ?)
     - user_consents (WHERE user_id = ?)
     - users (WHERE id = ?)
  → Ответ: 204 No Content
```

### 4.2. Требования к реализации

- Удаление должно быть **полным** (не soft-delete), если пользователь не отозвал согласие, а удалил аккаунт
- Должен быть **подтверждающий модал** в UI: «Все ваши данные будут безвозвратно удалены»
- Redis-кэш с данными пользователя должен быть очищен
- AI task store (`_tasks`, `_exports`) должен быть очищен для этого пользователя

### 5.1. Требуемый эндпоинт


## 6. Политика конфиденциальности — структура

### 6.1. Обязательные разделы

1. **Оператор ПД** — кто обрабатывает, контакты
2. **Какие данные собираются** — таблица из раздела 1.1
3. **Цели обработки** — для чего каждая категория данных
4. **Трансграничная передача** — какие данные, куда, зачем
5. **AI-обработка** — какие данные уходят в AI, что возвращается
6. **Хранение данных** — сроки хранения каждой категории
7. **Права субъекта ПД** — доступ, исправление, удаление, экспорт, отзыв согласия
8. **Контакты** — куда обращаться по вопросам ПД
9. **Изменения политики** — как уведомляем об обновлениях

### 6.2. Версионирование

- Каждая версия политики имеет номер (2026.1, 2026.2, ...)
- При изменении политики — повторный запрос согласия
- Хранить историю согласий в `user_consents`

## 7. AI-помощники: юридические риски по фичам

| Фича | Текущий статус | Юридический риск | Что нужно для запуска |
|------|---------------|-------------------|----------------------|
| AI-анализ объявления | Реализовано | Средний (советы по торгу, ROI) | Усиленный дисклеймер + согласие |
| AI-оценка состояния по фото | Реализовано | Низкий | Дисклеймер |
| AI-помощник продавцу | Реализовано | Низкий (генерация текста) | Согласие на AI + дисклеймер |
| AI-детект мошенничества | Не реализовано | Низкий | Дисклеймер |
| AI-аутентичность фото | Не реализовано | Низкий | Дисклеймер |
| AI-мониторинг цены («подожди/покупай») | Не реализовано | **Высокий** (инвестиционная рекомендация) | Явный дисклеймер «не инвестиционная рекомендация» + согласие |
| AI-переговорщик (генерация текста торга) | Не реализовано | Низкий | Согласие на AI |
| AI-оценка ликвидности | Реализовано | Средний | Дисклеймер «не гарантия» |

## 8. Варианты устранения трансграничной передачи

| Вариант | Провайдер | Юрисдикция | Сложность | Стоимость |
|---------|-----------|-------------|-----------|-----------|
| **Локальный LLM** | Llama 3 / Qwen на VPS в РБ | РБ | Высокая (GPU, деплой) | ~$50-200/мес GPU |
| **EU AI** | OVHcloud AI, Aleph Alpha, Mistral EU | ЕС | Средняя | ~$0.5-2/1K токенов |
| **Российский AI** | Yandex GPT, GigaChat | РФ (не ЕС, но не США) | Средняя | ~$0.3-1/1K токенов |
| **Гибрид** | Быстрые задачи — локально, полный анализ — облако | Смешанная | Средняя | Зависит от баланса |
| **Согласие + Google Gemini** | Оставить текущее, добавить согласие | США | Низкая | Текущая |

**Рекомендация:** На первом этапе — вариант «Согласие + Google Gemini» (минимальные изменения). На втором — исследовать EU-провайдеров.
