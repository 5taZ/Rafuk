# Impeccable Design Context for Rafuks

## Design Context

### Users
**Primary users**: Both pro resellers and casual shoppers on kufar.by (Belarus's largest classifieds platform)
- **Pro resellers**: Need speed, data density, deal-finding tools, profit tracking, market analysis
- **Casual shoppers**: Want price confidence, simple comparisons, clean browsing experience
- **Context**: Telegram Mini App on mobile devices, used in various lighting conditions (indoor/outdoor), quick sessions with frequent checks

### Brand Personality
- **Voice**: Technical but approachable, data-driven, no-nonsense
- **Tone**: Confident, precise, efficient
- **Personality**: Sharp, analytical, trustworthy
- **Emotional goals**: Confidence in pricing decisions, clarity in market data, satisfaction from finding deals

### Aesthetic Direction
- **Visual direction**: Linear/Vercel-inspired — clean surfaces, subtle depth, electric blue accent (#3b82f6), glassmorphism touches
- **Theme**: Dark-first (primary), with light mode support — auto-detected from Telegram colorScheme
- **References**: Linear.app, Vercel dashboard, Raycast — clean data surfaces, minimal chrome, strong typography
- **Anti-references**: Not a dashboard admin panel, not playful/consumer app, not gamified
- **Key principle**: Data is the hero — UI gets out of the way while making numbers feel premium

### Design Principles
1. **Surface hierarchy over borders** — Use elevation and subtle backgrounds, not thick borders, to create depth
2. **Density without crowding** — Pack useful data tightly but give each element breathing room
3. **Blue accent, semantic everything** — Electric blue (#3b82f6) for interactive elements; green/red/amber only for semantic meaning
4. **Motion as feedback, not decoration** — Subtle transitions confirm actions; no gratuitous animations
5. **Numbers demand respect** — JetBrains Mono for prices/numbers, treated as first-class UI citizens

## Technical Context
- **Framework**: Vanilla JavaScript SPA (no build step, no framework)
- **CSS**: Custom properties (design tokens), no Tailwind/Sass
- **Charts**: Chart.js 4.4
- **Font stack**: Rubik (sans-serif) + JetBrains Mono (monospace for numbers)
- **Delivery**: Served via Nginx in Docker Compose, loaded as Telegram Mini App
- **Architecture**: state + actions + renderers pattern (app_core.js, app_actions.js, app_renderers.js)
